# 0.4.37 검증 기록

## 수정

AI Studio · Argon 작업자를 생성할 때 남아 있던 Gemini CLI 설치 검사를 제외했습니다. 실제 실행은 기존 AIStudio2API 드라이버의 서비스 준비·인증·모델 확인을 따릅니다. 프로젝트 기본 모델, 채팅별 모델과 이전 Gemini 선택값을 지원하며, Gemini 웹 계정 선택과 기존 CLI 작업자의 설치 검사는 유지합니다.

## 검증 결과 (2026-11-05)

- 수정 전 새 회귀 검사에서 프로젝트·채팅·이전 설정의 세 경로 모두 `제미나이 CLI가 설치되지 않았습니다` 오류 재현.
- 수정 후 전체 단위 검사 436/436 통과. CLI 없이 AI Studio 작업자 생성·드라이버 선택·작업자 수 제한과 Claude/Codex/Grok의 CLI 필수 검사를 포함합니다.
- Node/Web TypeScript 타입 검사 통과.
- 격리 AI Studio UI 11/11, Provider UI 22/22 통과. 실제 계정 로그인이나 모델 생성을 수행하지 않는 UI 검사입니다.
- 로컬 AIStudio2API v0.2.13이 RUNNING 상태이며, 활성 계정 4개와 기존 런타임 키를 사용한 `/v1/models` 인증 및 `gemini-4-argon` 제공 확인. 키와 계정 내용은 기록하지 않았습니다.
- Electron Vite 및 Windows x64 NSIS 설치 파일 빌드 통과. 패키지 내부 빌드 출력 171개가 검사한 출력과 일치합니다.
- 기존 설치 경로에 v0.4.37.0 적용. 설치된 app.asar가 빌드 결과와 일치하고, 설치 전후 DB SHA-256이 동일한 것을 확인했습니다. 시작 메뉴는 직접 실행 파일을 가리키며 Windows 앱 목록에도 등록되어 있습니다.
- 설치본 창 제목 `AI ChatterBox v0.4.37`과 기존 대화 화면이 표시되는 것을 확인했습니다.

## 한계

실제 Argon 응답 생성과 한도 소진 후 계정 전환은 실행하지 않았습니다. 설치본의 전체 업무 시나리오는 실행하지 않았습니다.
