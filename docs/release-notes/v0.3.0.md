# AI_ChatterBox 0.3.0

채팅 하나에 지시하면 마스터가 일의 양에 맞춰 클로드·지피티 작업자 팀을 꾸려 구현과 리뷰를 나눠 맡기는 Windows 데스크톱 앱.

## 새 기능
- **마스터 + 작업자 팀**
  - 오케스트레이터가 마스터로 바뀌었습니다.
  - 마스터가 필요한 만큼 클로드 N호·지피티 N호를 만들고 해제합니다. 동시에 클로드 3명, 지피티 3명까지이고 프로젝트 설정에서 바꿀 수 있습니다.
  - 일을 맡길 때도, 작업자끼리 물을 때도 닉네임으로 부릅니다.
  - 고칠 범위가 겹치지 않는 구현과 리뷰는 동시에 진행됩니다.
  - 범위 밖 파일 쓰기는 자동으로 거부하고, 서로 기다리다 멈추는 순환 호출(교착)은 거절합니다.
  - 상단에 작업자 칩, 트리에 각 작업자와 "협의 N · 마스터 → 클로드 2호"를 표시합니다.
- **슬래시 명령**
  - `/plan`: 계획을 체크리스트로 보여 주고 실행 / 수정 요청 / 취소 버튼을 제공합니다.
  - `/goal`: 목표를 상단에 고정하고, 끝날 때까지 자동으로 이어서 진행합니다.
  - 그 밖에 `/review`, `/status`, `/model`, `/new`, `/stop`, `/compact`가 있습니다.
- **자동 승인 (0.2.1~)**: 작업자의 승인 요청은 마스터가 판단합니다. 위험한 요청만 사용자에게 묻습니다.
- **트레이와 이어서 진행 (0.2.1~)**
  - 작업 중에 창을 닫으면 트레이에서 계속 실행합니다.
  - 작업 중에 앱이 꺼졌다면 다음 실행 때 "이어서 진행"으로 남은 작업을 마칩니다.
- **모델**
  - 마스터·클로드·지피티 모델을 채팅별로 바꿀 수 있습니다.
  - 목록에는 계열별 최신 모델만 보입니다.
- **남은 사용량**: 주간 기준으로 보여 주고, 5시간 남은 양이 10% 이하일 때만 5시간 값을 보여 줍니다.

## 이전 버전에서 바뀐 점
- 같은 exe를 두 번 실행하면 빈 화면처럼 보이던 문제. 이제 같은 데이터로는 하나만 실행됩니다.
- 5분이 넘는 작업에서 마스터가 작업자의 결과를 놓치던 문제.
- Codex 앱이 같은 대화를 열고 있으면 이어지지 않던 문제. 이제 같은 기록을 복사한 새 대화로 이어서 진행합니다.

## 실행 방법
`AI_ChatterBox-0.3.0-portable.exe`를 실행하면 됩니다. exe는 저장소에 포함하지 않습니다. 소스에서 만들려면 `npm install` 후 `npm run dist`를 실행하세요.
- Claude Code(독립 설치본, 로그인)와 Codex가 PC에 설치되어 있어야 합니다.
- 서명하지 않은 exe라서 처음 실행할 때 SmartScreen이 막으면 "추가 정보 → 실행"을 누르세요.
