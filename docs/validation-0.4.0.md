- 실제 Claude 마스터가 앱 브리지로 Gemini 웹 작업자 1명을 생성하고 도서관 안내 문장을 `writing`으로 다듬게 했습니다. 웹 응답이 글쓰기 협의에 저장되고 마스터가 취합했습니다.

- 같은 작업자 재호출 시 이전 웹 대화와 동일 ID를 유지했습니다. 웹 토큰 사용량을 임의 생성하지 않았습니다.

- 중복 요청 거절, 수동 초안 보존, 실제 생성 중 중지와 웹 생성 종료를 확인했습니다.
- 반복 검증 중 Google `/sorry/index` 보안 확인으로 이동했습니다. 자동 재시도를 중단했고 사용자가 직접 확인한 뒤 로그인·사용량·중지 검증을 재개했습니다. 자동 사용량 조회는 최소 60초 간격으로 합칩니다.
