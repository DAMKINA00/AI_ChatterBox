# 0.4.59 — 공개 보고의 마스터 반복 방지

작업자가 `send_message(to=all)`로 메인 채팅에 보고하면 사용자와 동료는 그대로 읽을 수 있다. 이 공개 보고만으로 마스터에게 즉시 입력을 보내지 않는다. 마스터의 다음 도구 응답에는 이미 사용자에게 표시된 내용임을 명시한다.

마스터는 공개된 진행·결과를 바꿔 말하거나 요약해 재보고하지 않도록 지침을 보강했다. 새 결정·방침 변경, 사용자 질문, 미해결 충돌과 전체 최종 결론만 전달한다. 사용자가 재설명을 요청하면 답한다. 마스터의 즉시 판단이 필요한 질문은 직접 `send_message(to=마스터)`로 보내며 기존 즉시 전달·대기 해제 경로를 유지한다.

회귀 테스트는 공개 보고의 원문 보존, 동료 즉시 전달, 마스터 즉시 전달 제외, 직접 질문의 전달, 공개·비공개 메시지 구분, 수신함의 한 번 소비를 검사한다. 실제 모델의 문장 반복 여부는 별도 실사용 확인이 필요하며, 응답 내용을 임의로 삭제하는 필터는 추가하지 않았다.

빌드에는 이번 변경만 포함한다. 별도로 진행 중인 인증 확인·AIStudio 변경은 이 릴리스에 포함하지 않는다.

기존 커밋에 이 릴리스의 변경만 적용한 별도 소스에서 Node/Web 타입 검사와 전체 회귀 테스트 738/738이 정상 종료했다. 가짜 드라이버와 임시 DB를 사용했으며 실제 모델 작업은 실행하지 않았다.
