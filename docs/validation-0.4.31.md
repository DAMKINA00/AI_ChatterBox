# 0.4.31 검증 기록

2026-10-22, Windows x64.

## 변경

- 채팅 UI·트레이·파일 선택창은 일반 권한으로 실행하고, 마스터·작업자·승인 판단·데이터 처리는 별도 관리자 코어에서 실행합니다. Windows 승인 후 실행마다 다른 토큰으로 인증한 로컬 파이프를 사용합니다. 기존 앱의 도구 승인 정책은 유지합니다.
- Google 로그인 프로필은 기존 `electron` 폴더를 그대로 사용합니다. 채팅 UI는 `ui-electron` 프로필을 사용하고 기존 화면의 Local Storage를 최초 한 번 복사합니다. 데이터베이스는 코어 하나만 엽니다.
- 여러 파일을 끌어다 첨부할 수 있으며, 파일 하나가 실패해도 나머지를 처리합니다. 폴더는 첨부하지 않습니다.
- 대화 상단 검색 버튼과 `Ctrl+F`, 결과 강조·개수·이전/다음 이동·`Esc` 닫기를 추가했습니다. 마크다운·코드·첨부 파일명·도구 출력·협의 요청·파일 변경 내용도 검색하며, 검색하는 동안 접힌 내용을 펼칩니다.

## 범위와 한계

검사는 격리된 데이터 폴더를 사용했습니다. 일반 권한 UI와 관리자 코어의 실제 토큰은 확인했지만, 탐색기에서 마우스로 직접 끌어 놓는 수동 검사는 하지 않았습니다. 실제 유료 모델 대화·코딩·영상 생성, 실제 Google 재로그인 및 UAC 취소/재시도는 이번 변경에서 실행하지 않았습니다. Google 프로필 표식 보존은 실제 로그인 유효성 검사를 대신하지 않습니다.

실행기와 내부 앱은 `asInvoker`를 사용합니다. 파일 드롭을 위해 바로가기를 관리자 권한으로 실행하지 않아야 하며, 관리자 권한은 앱이 코어를 시작할 때 별도로 요청합니다.
