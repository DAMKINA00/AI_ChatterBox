## 원인과 수정

Microsoft Store Claude Desktop 4.23118.0.0의 실제 프로세스는 `%LOCALAPPDATA%\Claude-Data\claude_pzs8sxrjxfjjc`를 사용자 데이터 경로로 사용했습니다. 통합 모니터는 `%APPDATA%\Claude`만 읽었으며, 그곳의 이전 세션이 2026-11-09 03:34 KST에 만료되어 계정과 사용량이 표시되지 않았습니다. Desktop 자체는 새 경로에서 정상 로그인되어 있었습니다.

모니터가 새 경로를 우선 사용하도록 수정했습니다. 새 프로필이 없을 때만 이전 경로를 사용하며, 새 프로필에 인증이 없다고 이전 계정으로 돌아가지 않습니다. SQLite 저장소 열기·잠금 오류에는 Desktop을 트레이에서도 종료한 뒤 새로고침하는 방법을 안내합니다. 원본 프로필은 읽기 전용이며 인증값은 로그·설정·소스에 기록하지 않습니다.
