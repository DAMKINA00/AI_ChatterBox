# 0.4.36 검증 기록

## 변경 범위

- Claude·Codex·Grok 계열별 최대 10개 CLI 계정, 로그인/로그아웃/슬롯 삭제, 계정별 사용량, 전체/프로젝트 고정 정책과 마스터 배정.
- 다른 계정과 삭제 후 재생성된 계정의 세션을 이어 열지 않고 대화 요약을 인계. 계정 폴더 소유권·링크 검사와 프로세스 종료 확인 후 삭제.
- 승인 판단은 실제 마스터 계정과 동일한 환경/서버를 사용하며, 판단 중 계정 변경을 차단. 판정기 종료 실패 시 계정 폴더 보존.
- Gemini Antigravity CLI 실행·목록·사용량·승인 훅·설정 내보내기 제거. Gemini Web·AI Studio 및 Grok 유지. 이전 CLI 모델 선택값은 AIS로 읽으며 기존 기록과 계정 파일은 보존.
- 통합 사용량 모니터의 Antigravity 조회와 관련 트레이/호스트 프로토콜 메뉴 제거.

## 자동 검사

- Node/Web TypeScript 타입 검사 통과.
- 전체 단위 검사 430/430 통과. 제거된 Antigravity 전용 검사는 삭제하고, 기존 선택값 호환·Grok 유지·CLI 미호출·승인 판정 계정 분리 회귀 검사 추가.
- CLI 계정 브라우저 mock UI 43/43, 사용량 UI 9/9, Gemini UI 18/18, 추론 UI 25/25, Provider UI 22/22: 총 117/117 통과.
- Electron Vite 빌드 통과. 기존 CSS `::highlight` 호환 경고 2건은 남아 있음.
- 격리된 UI/코어 수명주기 검사 11/11 통과: 별도 프로세스, 첨부 전달, 업데이트 진입/취소, 종료/충돌 정리 및 대화 보존.
- Windows NSIS 설치 파일 빌드 및 패키지 내부 출력 파일 171개 일치 확인. UI/설치 파일의 `asInvoker` 매니페스트 확인.

## 검증 한계와 배포 원칙

화면 검사는 격리 데이터와 mock IPC를 사용했다. 실제 CLI 로그인/로그아웃, 유료 모델 생성, 실제 한도 소진 후 계정 변경은 이번 검증에서 실행하지 않았다. 영상 생성도 실행하지 않았다.

현재 실행 중인 0.4.35는 종료하거나 덮어쓰지 않는다. 설치 파일을 별도 준비하고 사용자가 종료 후 다시 실행할 때 적용한다. ChatterBox와 Usage의 기존 저장소 경로를 유지한다.

## 통합 사용량 모니터

- Release 빌드: 경고 0, 오류 0.
- C# 회귀 검사: 473 assertions, 0 failures. 삭제된 CLI 설정이 다시 조회를 활성화하지 않고 기존 계정 설정이 유지되는 검사 포함.
- 패키지의 실제 호스트 실행 검사는 현재 모니터의 중복 실행 방지로 시작되지 않았다. 사용 중인 앱을 유지하기 위해 종료하지 않았으며 이 검사를 통과한 것으로 집계하지 않는다.
