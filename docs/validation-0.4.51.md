# 0.4.51 검증

## 변경

- Gemini 실행·모델·승인·계정을 Antigravity CLI로 통합하고 추가 CLI 프로필을 분리합니다.
- Gemini 웹 드라이버·브라우저·계정 관리·IPC·마스터 도구와 관련 UI를 제거했습니다. 기존 웹·AI Studio 모델 설정은 네이티브 모델로 이전하며 대화·작업자·첨부 기록을 보존합니다.
- 사용량은 `Gemini Models` 그룹만 수집합니다. 주간·5시간 중 잔여량이 더 적은 한도 하나를 앱·원격 웹·통합 모니터에 표시합니다. Argon 및 Claude/GPT 모델 그룹은 제외했습니다.
- 성공한 사용량 조회는 해당 CLI 프로필의 로그인 상태도 갱신합니다. 로그아웃·계정 변경 전의 늦은 응답은 적용하지 않습니다.

## 확인 결과

- TypeScript 검사 통과, 단위 테스트 706/706 통과.
- 브라우저 계정·모델·사용량 UI 51개, Gemini UI 18/18, 공급자 UI 22/22, 추론 수준 UI 25/25 통과.
- 통합 사용량 모니터 hosted protocol 회귀 검사 64개 통과. 모니터 소스는 `fb9488bee265577560ed5681a40f9f5b8571f390`으로 고정했습니다.
- 패키지 앱 0.4.51을 별도 데이터 폴더에서 실행해 네이티브 모델 11개, 웹 연결 API·메뉴 제거, 기존 웹 모델 이전, 실제 로그인 계정 사용량과 화면의 최소 잔여량 일치, 추가 프로필의 별도 로그인 필요 상태를 확인했습니다.
- 패키지 ASAR의 앱 출력 파일 175개가 빌드 출력과 일치합니다. 네이티브 승인 훅과 MCP 브리지가 unpack되어 있고 모니터 실행파일·DLL도 고정된 소스의 publish 결과와 일치합니다.

## 범위와 제한

설치된 0.4.49 앱은 실행 중이므로 종료하거나 덮어쓰지 않았습니다. 실제 계정으로 모델 턴을 실행하지 않고 사용량·모델 목록만 조회했습니다. 이번 사용량 표시는 Gemini 일반 그룹 기준이며, 제외한 Argon 등 모델의 실제 실행 한도를 보장하지 않습니다. 실제 Google 계정 두 개의 신규 OAuth 로그인은 수행하지 않았습니다.
