# Antigravity CLI로 Gemini 사용

Gemini는 설치된 Antigravity CLI(`agy`)를 사용합니다. Gemini 웹이나 AIStudio2API 연결은 필요하지 않습니다. 기존 웹·AI Studio 모델 선택은 CLI 기본 Argon 모델로 이전하며 대화 기록을 유지합니다.

## 로그인과 계정

1. 설치된 Antigravity CLI를 실행해 로그인합니다. Windows 기본 경로는 `%LOCALAPPDATA%\agy\bin\agy.exe`입니다.
2. 앱의 **CLI 계정 관리 → Antigravity**에서 상태를 새로고침합니다. 모델 목록은 해당 CLI 계정이 실제 제공하는 모델을 표시합니다.
3. 기본 계정은 평소 사용하는 CLI 로그인을 사용합니다. 추가 계정은 **계정 추가 → 로그인**으로 각각 인증하며, 별도 폴더에 로그인·대화·사용량을 저장합니다. 계열별 최대 10개입니다.
4. Claude·Codex와 동일하게 프로젝트·전역의 고정, 잔여량 판단, 우선 순서 정책을 적용합니다. 기본 계정의 로그아웃은 평소 CLI 로그인에도 영향을 줍니다.

마스터와 작업자 모두 CLI를 사용할 수 있습니다. 작업 종류는 사용자의 지정과 실제 도구·가용성을 따르며 파일 변경과 명령 실행은 기존 승인과 범위를 따릅니다.

## 사용량

`agy -p /usage --output-format json`으로 모델 턴을 실행하지 않고 조회합니다. **Gemini Models** 그룹의 주간·5시간 중 잔여량이 더 적은 한도 하나와 그 초기화 시각을 표시합니다. Argon 및 Claude/GPT 모델 그룹은 표시 대상에서 제외합니다. 이는 해당 모델을 실행할 수 있다는 보장이 아니므로 실제 실행의 모델별 한도 오류는 그대로 보고합니다.

앱 사이드바, CLI 계정 관리, 원격 웹과 통합 사용량 모니터는 같은 조회값을 사용합니다. 계정별 조회 시각과 오류도 유지합니다.
