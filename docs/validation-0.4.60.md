# 0.4.60 — 승인 판정기의 전체 위험 승인 적용

‘전체 위험 승인’ 상태에서 승인 판정기가 확인용 PowerShell 등을 호출하면, 재귀 판정을 막는 내부 경로가 승인 설정과 관계없이 사용자 확인을 요구했다. 이제 전체 위험 승인일 때는 판정기의 도구 요청도 자동 처리하며 별도 판정기를 다시 호출하지 않는다. 처리 내역은 자동 승인 기록에 남긴다.

일반 자동 승인·수동 승인 모드에서는 기존 확인 절차를 유지한다. 중지·취소, 실행 제한과 지정된 쓰기 범위 검사는 자동 처리보다 먼저 적용하며 원래 작업에 대한 판정기의 명시적 거부도 유지한다. 판정기 지침도 현재 채팅 승인 설정을 따르도록 맞췄다.

수정 전 테스트에서 전체 위험 승인인데도 사용자 승인 요청 1개가 생기는 것을 재현했다. 관련 테스트는 PowerShell 확인 요청, 기존 고위험 위임 설정, 사용자 직접 승인 모드, 재귀 판정 방지, 작업 범위·취소, 확인 작업 뒤 원래 요청의 허용/거부를 검사한다. 가짜 드라이버와 임시 DB를 사용하며 실제 PowerShell 명령이나 모델 작업을 실행하지 않는다.

별도로 진행 중인 인증 확인·AIStudio 변경은 포함하지 않는다.

이 릴리스의 변경만 적용한 별도 소스에서 Node/Web 타입 검사와 전체 테스트 741/741이 정상 종료했다. 관련 승인 회귀 47개도 통과했다.
