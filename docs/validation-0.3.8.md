# AI_ChatterBox 0.3.8 검증 기록

검증일: 2026-10-14. 실행 중인 사용자 앱·작업은 유지했습니다.

## 원인과 수정

- PowerShell은 `agy` 명령을 찾지 못했지만 `%LOCALAPPDATA%\agy\bin\agy.exe` 파일은 존재했습니다. 전체 경로로 실행한 `--version`과 `models`가 정상 응답했고, 사용자 PATH에는 해당 폴더가 빠져 있었습니다.
- 기존 사용자 PATH를 백업하고 해당 폴더만 추가했습니다. Windows 환경 변경 알림을 전달하고, 저장된 사용자·시스템 PATH를 받은 별도 Windows PowerShell에서 `Get-Command agy`, `agy --version`, `agy models`가 성공하는 것을 확인했습니다. CLI는 1.3.5이며 실제 Pro 계정에서 Gemini 모델 3개를 조회했습니다. 열려 있던 터미널은 기존 환경을 유지할 수 있습니다.
- 실행 중인 앱의 패키지는 0.3.7이었습니다. 상단 설치 경고는 최초 `cliInfo()` 값을 계속 사용해 모델 목록 재조회 이후에도 갱신되지 않는 문제가 있었습니다. 최초 탐색 실패 당시의 프로세스 환경은 확인하지 못했으므로 PATH 누락만으로 앱의 최초 오류까지 설명하지는 않습니다.
- 상단에 **설치 경로 다시 확인** 버튼을 추가했습니다. 모델 재조회와 설치 후 앱으로 돌아올 때에도 CLI 경로를 다시 검사합니다. 설치 확인은 모델 실행이나 실행 중인 작업 중단 없이 진행합니다. 재확인 실패 시 기존 경고를 유지하고 직접 재확인 중의 오류는 표시합니다.

UI의 설치 누락·복구 상황은 IPC 응답을 주입해 검사했습니다. 실제 CLI·로그인·모델 목록·사용량 조회와 구분됩니다. 설치 버튼, 모델 재조회, 창 포커스 회복으로 경고가 사라지고 실제 미설치 상태에서는 경고가 유지되는 것을 확인했습니다. 모델 작업을 실행하는 검사는 이번 변경에 포함하지 않았습니다.

현재 사용자 앱의 재시작·UAC 실동작은 재검사하지 않았습니다. 진행 중인 작업이 끝난 뒤 새 포터블을 적용합니다. PowerShell PATH 복구는 이미 적용돼 있습니다.
