# Gemini 웹 계정 1

## 연결

1. 진행 중인 작업이 끝난 뒤 0.4.0 포터블을 실행합니다.
2. 프로젝트 설정 또는 채팅 상단의 제미나이 모델 메뉴에서 **웹 계정 1 연결…**을 엽니다.
3. **로그인 브라우저 열기**를 눌러 Google 계정으로 직접 로그인합니다.
4. **새로 확인** 후 **Argon 모델 사용**을 누릅니다. 프로젝트 설정에서 변경했다면 저장합니다.
5. 마스터에게 “제미나이에게 이 문장을 다듬게 해줘” 또는 “이 캐릭터의 대사를 써줘”처럼 요청합니다. 배정·웹 응답·최종 취합이 앱 대화에 남습니다.

계정이 이미 연결되어 있으면 기존 로그인을 사용합니다. 이 버전은 계정 슬롯 하나를 제공하며 다른 계정의 동시 작업은 지원하지 않습니다.

## 지원 범위

- 웹·CLI Gemini는 모두 글쓰기 전용입니다. 문장 다듬기·캐릭터 대사·시나리오·문서 본문·요약·번역을 `writing`으로 배정합니다. `implement/review/opinion` 기술 배정은 앱에서 거부합니다. 필요한 내용은 요청 본문 또는 UTF-8 텍스트 첨부로 전달합니다. 파일당 200KB, 요청 전체 300,000자까지입니다.
- 기술 문서는 클로드·지피티가 검증한 사실을 제미나이에 전달해 문장과 구성을 다듬고, 클로드·지피티가 최종 기술 확인과 파일 반영을 맡습니다. 코드 분석·버그 수정·테스트·기술 리뷰의 대체 인력으로 제미나이를 쓰지 않습니다. 캐릭터 대사는 성격·관계·상황·말투 예시를 함께 전달합니다.
- 로컬 폴더 탐색·파일 수정·명령·MCP 도구를 실행하지 않습니다. 이미지/PDF 업로드, 웹 이미지 생성·다운로드 연동은 포함하지 않습니다.
- 웹 추론 수준·토큰 수·tok/s를 임의로 만들지 않습니다. 메뉴에는 **웹 모델 설정**을 표시하며 마스터의 난이도 선택은 배정 의도로 기록합니다.
- 재호출은 저장된 웹 대화 ID를 사용합니다. 대화가 없거나 Argon 선택을 확인하지 못하면 오류로 보고합니다.
- 한 계정의 동시 요청은 하나입니다. 다른 채팅에서 사용 중이면 마스터에게 재배정 가능한 오류를 돌려줍니다.
- 직접 작성 중인 초안이나 응답이 있으면 덮어쓰지 않습니다. 브라우저에서 마무리한 뒤 다시 요청합니다.
- 중지는 웹의 응답 중지 버튼을 누르고 협의를 중단 상태로 남깁니다. Google 서버 쪽 취소 시점까지 보장하지는 않습니다.
- 앱 기록과 웹 대화를 유지합니다. 원본 웹 대화 자동 보관·삭제는 포함하지 않습니다.

## 사용량

[Gemini 사용량 한도](https://gemini.google.com/usage)의 **현재 사용량**, **주간 한도**, **초기화 시각**을 같은 로그인 세션의 별도 숨김 페이지에서 읽습니다. 진행 중인 채팅 주소는 바꾸지 않습니다.

왼쪽 **Gemini 웹 · 계정 1**에 잔여율을 표시합니다. 주간이 기본이며 현재 잔여량이 10% 이하이면 현재 한도를 보여 줍니다. 마우스를 올리면 양쪽 사용률·초기화 시각·마지막 조회 시각을 확인합니다. CLI 사용량은 별도 행입니다.

앱 시작·5분 주기·작업 전후에 확인하되 자동 조회는 최소 60초 간격으로 합칩니다. 새로 확인은 즉시 조회합니다. 수치가 없거나 조회가 실패하면 비율을 추정하지 않습니다. 계정 전체의 웹 표시 수치이며 반올림될 수 있습니다.

## 로그인과 보안 확인

전용 브라우저는 Electron 격리 세션을 사용하며 Node 접근·앱 preload·외부 디버깅 포트를 제공하지 않습니다. 로그인은 `%APPDATA%\AI_ChatterBox\web-accounts\gemini-1`에 저장하며 CLI 인증과 분리합니다.

Google이 추가 보안 확인을 요구하면 자동 호출을 멈춥니다. **브라우저 열기**로 이동해 직접 확인한 뒤 **새로 확인**을 누릅니다. 보안 확인을 자동 통과하거나 우회하지 않습니다.

웹 구조가 바뀌면 응답·사용량 수집이 실패할 수 있습니다. 실패한 협의는 완료로 처리하지 않으며 확인된 결과와 미완료 사유를 마스터에게 전달합니다.
