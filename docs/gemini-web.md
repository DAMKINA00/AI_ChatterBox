# Gemini 웹 계정 관리

## 연결

1. 진행 중인 작업이 끝난 뒤 0.4.4 포터블을 실행합니다.
2. 프로젝트 설정 또는 채팅 상단의 제미나이 모델 메뉴에서 **웹 계정 관리…**을 엽니다.
3. **계정 추가**로 필요한 계정을 등록하고 각 계정의 **로그인 / 브라우저**에서 Google 계정으로 직접 로그인합니다. 계정은 최대 10개입니다.
4. 로그인 중에는 해당 계정 카드에 진행 상태를 표시합니다. 로그인 완료를 확인하면 계정 번호가 포함된 안내를 표시하고 로그인 창을 자동으로 숨깁니다. 초안이나 생성 중인 응답이 있으면 내용을 유지하고 창도 그대로 둡니다. 이미 연결된 계정의 **로그인 / 브라우저**를 누르면 수동으로 창을 열며 자동으로 숨기지 않습니다.
5. **사용량 확인** 후 **Argon 자동 배정 사용**을 누릅니다. 프로젝트 설정에서 변경했다면 저장합니다. 계정 이름과 **자동 배정** 여부는 관리 화면에서 변경합니다.
6. 마스터에게 “제미나이에게 이 문장을 다듬게 해줘” 또는 “이 캐릭터의 대사를 써줘”처럼 요청합니다. 배정·웹 응답·최종 취합이 앱 대화에 남습니다.

기존 계정 1의 로그인과 대화를 유지합니다. 계정마다 로그인 저장소와 작업 잠금을 분리하며 계정 하나에는 작업 하나만 배정합니다. 작업자 수는 기존 프로젝트 설정을 따릅니다. 왼쪽 아래 **Gemini 웹 계정 관리**에서도 관리 화면을 열 수 있습니다.

## 지원 범위

- 웹·CLI Gemini는 모두 글쓰기 전용입니다. 문장 다듬기·캐릭터 대사·시나리오·문서 본문·요약·번역을 `writing`으로 배정합니다. `implement/review/opinion` 기술 배정은 앱에서 거부합니다. 필요한 내용은 요청 본문 또는 UTF-8 텍스트 첨부로 전달합니다. 파일당 200KB, 요청 전체 300,000자까지입니다.
- 기술 문서는 클로드·지피티가 검증한 사실을 제미나이에 전달해 문장과 구성을 다듬고, 클로드·지피티가 최종 기술 확인과 파일 반영을 맡습니다. 코드 분석·버그 수정·테스트·기술 리뷰의 대체 인력으로 제미나이를 쓰지 않습니다. 캐릭터 대사는 성격·관계·상황·말투 예시를 함께 전달합니다.
- 로컬 폴더 탐색·파일 수정·명령·MCP 도구를 실행하지 않습니다. 이미지/PDF 업로드, 웹 이미지 생성·다운로드 연동은 포함하지 않습니다.
- 웹 추론 수준·토큰 수·tok/s를 임의로 만들지 않습니다. 메뉴에는 **웹 모델 설정**을 표시하며 마스터의 난이도 선택은 배정 의도로 기록합니다.
- 같은 계정을 다시 배정하면 저장된 웹 대화 ID를 사용합니다. 다른 계정으로 옮길 때는 기존 요청·완료 응답과 현재 초안을 전달해 새 대화를 시작합니다. 대화가 없거나 Argon 선택을 확인하지 못하면 오류로 보고합니다. 이전 맥락을 포함한 요청이 300,000자를 넘으면 초안과 원래 대화를 보존하고 중단합니다. 이 경우 새 채팅에 핵심 맥락을 요약해 전달합니다.
- 이전에 작업하던 계정의 잔여 한도를 먼저 확인합니다. 작업 중이 아니고 현재·주간 잔여율의 최솟값이 10%를 넘으면 같은 계정과 웹 대화를 이어서 사용합니다. 이전 계정을 사용할 수 없으면 쉬고 있는 계정 중 잔여율이 가장 큰 계정에 배정합니다. 자동 배정에서 제외한 계정과 로그인·보안 확인이 필요한 계정은 선택하지 않습니다. 확인되지 않은 한도를 충분한 잔여량으로 간주하지 않습니다.
- 모두 작업 중이거나 한도가 부족하면 협의를 완료 처리하지 않고 배정 대기 상태를 유지합니다. 10초마다 작업 상태를 확인하고 계정별 한도는 최소 60초 간격으로 실제 웹 화면에서 다시 조회합니다. 작업이 끝나거나 한도가 초기화되면 같은 순서로 배정합니다. 이 요청에서 사용했던 계정도 초기화 후 다시 사용할 수 있습니다. 로그인·조회 오류는 계정 관리에서 해결할 수 있으며, 중지 버튼으로 대기를 취소합니다.
- 직접 작성 중인 초안이나 응답이 있으면 덮어쓰지 않고 다른 계정을 확인합니다. 브라우저에서 작업을 마무리하면 다음 배정 확인에 반영합니다.
- 중지는 웹의 응답 중지 버튼을 누르고 협의를 중단 상태로 남깁니다. Google 서버 쪽 취소 시점까지 보장하지는 않습니다.
- 앱 기록과 웹 대화를 유지합니다. 원본 웹 대화 자동 보관·삭제는 포함하지 않습니다.

## 사용량

[Gemini 사용량 한도](https://gemini.google.com/usage)의 **현재 사용량**, **주간 한도**, **초기화 시각**을 같은 로그인 세션의 별도 숨김 페이지에서 읽습니다. 진행 중인 채팅 주소는 바꾸지 않습니다.

웹 사용량은 **Gemini 웹 계정 관리** 안에서 계정별 현재·주간 잔여율로 표시합니다. 마우스를 올리면 초기화 시각과 마지막 조회 시각을 확인합니다. 메인 화면에는 웹 사용량을 별도로 표시하지 않으며 CLI 사용량 행은 유지합니다.

배정 전·작업 중·작업 후에 확인하되 계정별 자동 조회는 최소 60초 간격으로 합칩니다. **사용량 확인**은 즉시 조회합니다. 수치가 없거나 조회가 실패하면 비율을 추정하지 않습니다. 계정 전체의 웹 표시 수치이며 반올림될 수 있습니다.

응답을 생성하는 도중 잔여율이 10% 이하가 되거나 한도에 도달하면 현재 생성을 멈추고 요청·대화 맥락·초안을 보존합니다. 쉬고 있는 계정 중 잔여량이 가장 많은 계정으로 인계하며, 사용할 계정이 없으면 작업 완료 또는 한도 초기화를 기다립니다. 후속 계정이 작성한 전체 최종 응답을 같은 협의의 결과로 기록합니다. 중지를 누르면 진행 중인 응답과 배정 대기를 함께 중단합니다.

## 로그인과 보안 확인

전용 브라우저는 Electron 격리 세션을 사용하며 Node 접근·앱 preload·외부 디버깅 포트를 제공하지 않습니다. 로그인은 `%APPDATA%\AI_ChatterBox\web-accounts\gemini-1`부터 `gemini-10`까지 각 계정 폴더에 저장하며 CLI 인증과 분리합니다.

Google이 추가 보안 확인을 요구하면 자동 호출을 멈춥니다. **로그인 / 브라우저**로 이동해 직접 확인합니다. 로그인 연결은 Gemini 입력창과 모델 표시가 확인될 때 완료로 알립니다. 로그인 중 창을 직접 닫으면 확인을 취소하고 세션은 보존합니다. 보안 확인을 자동 통과하거나 우회하지 않습니다.

0.4.4부터 Google 로그인이 새 창을 열면 같은 계정 세션의 별도 로그인 창으로 유지합니다. 로그인 팝업에서 Gemini 연결을 확인하면 원래 창을 갱신하고 완료 안내를 표시합니다. Google의 중간 쿠키 인계 주소는 허용하지만 다른 사이트로의 이동은 차단합니다. 차단된 주소는 비밀번호·인증값이 없는 호스트와 경로만 오류에 표시합니다. 로그인 창에 직접 작성 중인 내용이 있으면 먼저 마무리해 주세요.

웹 구조가 바뀌면 응답·사용량 수집이 실패할 수 있습니다. 실패한 협의는 완료로 처리하지 않으며 확인된 결과와 미완료 사유를 마스터에게 전달합니다.
