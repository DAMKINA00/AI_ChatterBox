## 알려진 제한

- 작업자는 사용자의 `~\.codex` / `~\.claude` 설정(스킬, 훅, MCP 서버)을 그대로 씁니다. 그래서 Codex 작업자가 사용자 스킬(예: ponytail)을 읽는 모습이 보일 수 있고, 앱에서 만든 Codex 스레드는 Codex 앱 기록에도 남습니다.
- 작업 폴더 밖 파일 **읽기**(예: `~\.codex` 스킬 파일)는 0.2.1부터 자동 허용됩니다. 작업 폴더 밖 **쓰기**는 자동 승인 모드에서도 매번 묻습니다.
- 두 작업자는 같은 폴더에서 차례로 일합니다 (worktree 분리는 아직 없음).
- 0.2.0은 같은 exe를 두 번 실행하면 두 번째 창이 마지막 채팅을 못 열어 빈 화면처럼 보였습니다 (데이터는 그대로). 0.2.1은 두 번 열리지 않습니다.
- 서명하지 않은 exe입니다. 설치 프로그램(NSIS)과 자동 업데이트는 없습니다.
