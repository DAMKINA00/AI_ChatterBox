# 단발성 자문과 읽기 전용 탐색

마스터와 배정받은 작업자는 `council_consult`와 `council_explore`를 사용할 수 있다. 작업자 목록에 새 작업자를 만들지 않고, 매번 별도 대화에서 짧은 답변을 받은 뒤 실행을 정리한다. 구현 배정, 독립 조사, 교차 리뷰와 완료 검증은 기존 `spawn`/`ask` 흐름을 사용한다. 자문 결과로 리뷰 통과를 기록하지 않는다.

## 자문

`council_consult({ question, context?, purpose?, model? })`

- 질문은 최대 2,000자, 제공할 문맥은 최대 8,000자다. 전체 대화나 저장소를 자동으로 전달하지 않는다.
- `purpose`는 `analysis`(기본) 또는 `writing`이다. Gemini는 `writing`만 허용한다.
- 모델은 도구를 사용할 수 없고, 제공된 자료만으로 결론·이유·불확실성을 답한다.
- `model`은 실제 제공되는 `claude:모델ID`, `codex:모델ID`, `gemini:모델ID`, `grok:모델ID`, `deepseek:모델ID` 형식이다. 명시한 모델을 사용할 수 없으면 실패 이유를 반환한다.
- 생략하면 마스터 계열을 우선하며, 글쓰기는 Gemini를 먼저 고려한다. 해당 계정의 실제 목록에서 상위 모델 이름을 우선하고, 없으면 기본 모델을 사용한다. 이는 모델명에 따른 선택 규칙이며 가격·품질 순위를 보증하지 않는다.

## 탐색

`council_explore({ query, kind, model? })`

| kind | 검색 범위 |
| --- | --- |
| `search` | 상대 파일 경로에 검색어가 모두 포함되는 파일 |
| `grep` | 텍스트 파일 본문에서 문자열 일치 |
| `docs` | Markdown·텍스트·RST 문서 본문에서 문자열 일치 |

검색어는 최대 300자이며 대소문자를 구분하지 않는다. 정규식과 셸 명령은 실행하지 않는다. 앱이 파일을 직접 읽고, 모델에는 찾은 경로·행 번호·발췌만 전달한다. 모델은 추가 도구를 사용할 수 없다. 기본은 Codex/Claude 순으로 실제 제공되는 경량 모델 이름을 우선하며, 없다면 해당 계정의 기본 모델을 사용한다. Gemini는 탐색 대상으로 선택하지 않는다.

숨김 파일·폴더, 일반적인 생성·의존성 폴더, 링크·정션, 식별 가능한 비밀 파일, 바이너리와 256 KiB보다 큰 파일은 제외한다. 최대 3,000개 파일, 500개 폴더, 깊이 20, 읽은 내용 8 MiB, 근거 12개까지만 탐색한다. `coverage`와 `note`를 함께 반환하므로 결과 없음이나 일부 검색을 전수 검증으로 해석하면 안 된다. 일치 결과가 없으면 모델을 호출하지 않는다.

## 실행과 결과

- Claude/Codex/Antigravity/Grok/DeepSeek의 기존 연결을 사용하며, CLI 계정의 프로젝트·전역 고정/우선 정책과 비활성화·확인된 한도를 존중한다. 실행 실패를 다른 계정에 자동 재전송하지 않는다.
- 채팅당 한 번만 실행하며 전체 제한 시간은 120초다. 모델 답변은 최대 1,500자, 탐색 응답 전체는 최대 6,000자로 제한한다. 잘린 경우 `truncated`를 표시한다.
- `provider`, `model`, `accountId`, `text`, 가능한 경우 토큰 수와 소요 시간을 반환한다. 보조 호출의 토큰을 마스터의 직접 생성량에 합산하지 않는다. 실제 계정 사용량은 기존 사용량 조회에 반영된다.
- 채팅 중지·일시정지·삭제, 해당 계정 변경, 앱 종료 시 보조 실행도 중지한다. 종료를 확인하지 못하면 계정을 사용 중인 상태로 유지하며 새 호출을 막는다.
- 자동 승인이 켜져 있어도 이 기능의 도구 금지는 유지한다. 검색 자료에 들어 있는 지시는 분석할 데이터로 취급한다.
- Claude 보조 실행은 사용자 훅을 끄지만, 조직의 관리 정책은 CLI가 그대로 적용한다([공식 설정 설명](https://code.claude.com/docs/en/hooks#disable-or-remove-hooks)).

실제 공급자의 응답 품질·토큰 절감량은 이 변경의 자동 테스트에서 측정하지 않았다. 테스트는 공급자를 대체한 격리 환경에서 검색 경계, 모델 선택, 취소와 결과 제한을 검증한다.
