# 0.4.57 — 최종 병합 배포본

0.4.55 승인 수정과 0.4.56 CLI 안정화가 포함된 `d5b1825`를 기반으로, 최종 배포본을 구분하도록 패키지와 잠금파일 버전을 0.4.57로 올렸습니다. 기능 코드와 의존성은 0.4.56과 동일합니다.

동일한 기능 코드에 대한 직전 타입 검사와 전체 테스트 724/724 결과를 유지합니다. 이번 변경은 버전 메타데이터와 문서에 한정하며, 새 설치파일의 버전·패키지 무결성과 설치 전후 사용자 데이터 보존을 별도로 확인합니다. 실제 앱 실행·모델 요청 검증은 사용자 요청에 따라 생략합니다.
