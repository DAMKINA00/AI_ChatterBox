# DeepSeek API

0.4.18부터 DeepSeek를 마스터와 작업자로 사용할 수 있습니다. 기존 Claude·Codex·Gemini Web·AI Studio·Grok 연결 설정과 대화는 유지됩니다.

## 연결

1. 모델 선택 메뉴 또는 사용량 영역에서 **DeepSeek API 설정**을 엽니다.
2. [DeepSeek 플랫폼](https://platform.deepseek.com/api_keys)에서 발급한 키를 입력하고 **저장**합니다. 빈 입력으로 저장하면 기존 키를 유지하며, 삭제는 **키 삭제** 버튼으로 처리합니다.
3. **모델 확인**을 누릅니다. 공식 서버의 모델 목록만 조회하므로 대화나 이미지·영상을 생성하지 않습니다. 연결 성공은 API 잔액이나 모든 모델의 생성 성공을 보장하지 않습니다.
4. 프로젝트 설정 또는 채팅 상단에서 DeepSeek 모델을 선택합니다. 마스터는 `deepseek:deepseek-flash`, 작업자는 `deepseek-flash`를 기본으로 사용합니다. 기본 DeepSeek 작업자 수는 3명이며 프로젝트별로 조절합니다.

API 주소는 공식 `https://api.deepseek.com`으로 고정합니다. 키는 Electron safeStorage를 통해 현재 Windows 계정으로 암호화하여 저장합니다. 설정 화면에 저장된 키를 다시 반환하지 않으며, 다른 PC나 Windows 계정에서는 키를 다시 입력해야 할 수 있습니다.

## 모델과 도구

- 2026-10-20 공식 문서 기준 기본 모델은 `deepseek-flash`(DeepSeek-V4.1-Flash-1017), 상위 모델은 `deepseek-v4-pro`입니다. 모델 확인에서 추가 모델이 제공되면 목록에 반영하며, 호출 전에 실제 계정의 모델 목록을 확인합니다.
- 공식 추론 수준은 `low`, `high`, `max`입니다. 마스터는 `none`으로 추론을 끌 수 있습니다. 기존 작업자 자동 배정 체계의 `medium`과 `xhigh`는 DeepSeek API에서 둘 다 `high`로 매핑됩니다. `max`는 마스터 모델 설정에서 선택할 수 있습니다.
- 파일 읽기·목록·수정·명령 실행과 ChatterBox 협업 도구를 지원합니다. 프로젝트 범위 및 기존 승인 정책을 적용하고, 승인 판단 세션은 도구 없이 실행합니다. 이미지·영상 생성 도구는 제공하지 않습니다.
- 추론 내용은 도구 사용을 이어갈 수 있도록 내부 대화 기록에 보관해 후속 API 요청에 전달합니다. 화면에는 일반 응답을 표시합니다. 스트림 중단이나 불완전한 도구 호출을 성공으로 처리하지 않습니다.
- 응답에서 받은 입력·출력·캐시 토큰을 기존 작업 통계에 기록합니다. DeepSeek API 요금은 별도이며 Gemini 구독 한도를 공유하지 않습니다. 잔액이나 잔여 요청량을 추정하지 않습니다.

## 검증 범위

서비스 테스트는 키의 암호화 저장 경로, 비밀값 미노출, 공식 주소 제한, 연결 확인의 GET 요청, 오류 처리와 키 삭제 중 늦게 도착한 응답을 검사합니다. 모의 API를 이용한 코딩 테스트는 실제 임시 파일의 `a-b`를 `a+b`로 수정하고 Node assertion을 실행한 뒤, 재생성한 드라이버에서 추론·도구 결과가 보존되는지 확인합니다. 실제 DeepSeek 계정에 유료 요청을 보낸 검증과는 구분합니다.

기존 4개 제공자 DB에서 작업자 번호·세션·해제 상태·Gemini 웹 계정 연결과 이벤트를 보존하는 마이그레이션, DeepSeek 설정 저장·재실행·대화 삭제, 작업자 상한을 별도로 검사합니다.

2026-10-20, 0.4.18 검증 결과: TypeScript 두 프로젝트와 프로덕션 빌드 통과, 단위 테스트 315/315, DeepSeek 화면 15/15, 헤더 화면 12/12, AI Studio 공유 계정 화면 9/9, 사용량 화면 10/10 통과. DeepSeek 화면 테스트는 실제 Windows 암호화 저장·삭제를 확인하며, 모델 조회와 생성 응답은 모의 서버를 사용합니다. 캐릭터 73개 PNG 전체의 디코딩·크기·투명도를 검사했고 새 DeepSeek 12개 표정을 갤러리에서 확인했습니다. 실제 DeepSeek 서비스 대화·코딩은 API 키가 없어 검증하지 않았습니다.

참조: [공식 API 시작 안내](https://api-docs.deepseek.com/), [추론과 도구 호출](https://api-docs.deepseek.com/guides/thinking_mode/).
