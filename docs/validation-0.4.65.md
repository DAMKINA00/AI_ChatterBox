# v0.4.65 — Codex 모델 목록

2026-11-23, Windows x64.

## 원인과 수정

v0.4.63부터 독립 Codex 설치 경로를 무조건 우선했습니다. 이 PC의 독립 CLI 0.164.0은 6.1 계열까지만 반환했지만, 같은 계정으로 조회한 Desktop CLI 0.167.0-alpha.3.2와 0.171.0-alpha.13은 6.2-Sol·6.2-Astra를 반환했습니다. 메뉴 필터가 새 모델을 지운 것이 아니라 앱이 오래된 CLI를 선택한 문제였습니다.

`findCodex`가 명시적인 경로 설정을 우선하고, 자동 탐색에서는 설치된 후보의 실제 버전을 비교합니다. 모델 조회와 작업 실행은 같은 선택 함수를 사용합니다. 버전은 파일 변경 시각·크기가 바뀔 때 다시 확인하며, 조회 프로세스에는 시간 제한과 창 숨김 옵션을 적용했습니다. 버전 확인에 모두 실패해도 발견된 CLI를 사용할 수 있습니다.

## 검증

- TypeScript main/renderer 및 Electron Vite 빌드 통과.
- 단위 테스트 780개 통과. CLI 선택 회귀 테스트는 최신 버전, 명시 경로, prerelease 비교, 조회 캐시, 조회 실패와 미설치를 포함합니다.
- 실제 Codex app-server의 읽기 전용 모델 조회에서 6.2-Sol·6.2-Astra 확인.
- 별도 데이터 폴더로 실제 Electron 앱을 열어 두 모델이 메뉴에 나타나고 `목록에 없음` 표시가 없는지 확인. 생성 작업은 요청하지 않았습니다.
- 이 PC의 오래된 독립 CLI 릴리스 7개(0.154.0~0.164.0)와 연결을 제거하고, 기존 CLI 전용 계정 경로를 유지하면서 설치된 Desktop과 같은 0.171.0-alpha.13 실행 파일을 실제 runtime 폴더에 배치했습니다. 터미널 `codex --version`도 같은 버전입니다. 이 정리는 해당 PC에서만 수행하며 앱 업데이트가 다른 PC의 CLI를 자동 삭제하지는 않습니다.

모델의 이용 가능 여부는 해당 CLI 계정과 서버 응답에 따릅니다. 실제 모델 생성이나 작업 실행은 이번 검증에 포함하지 않았습니다.
