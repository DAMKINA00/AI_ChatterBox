# Graphify 코드 지식 그래프

프로젝트 이름을 우클릭하거나 더보기 메뉴에서 **프로젝트 그래프**를 선택합니다. **Graphify 설치 → 그래프 생성** 순서로 실행합니다. Python 3.10 이상이 필요하며 최초 설치는 PyPI에서 `graphifyy==0.9.93`과 의존 패키지를 내려받습니다. 앱은 전용 가상 환경을 사용하고 시스템 Python 패키지나 다른 앱의 Graphify 설치를 변경하지 않습니다.

코드 작업에서는 마스터가 `route_request(codeWork=true)`로 작업을 분류합니다. 앱이 프로젝트별 기존 그래프를 먼저 확인하고, 없으면 설치와 최초 추출이 끝날 때까지 기다립니다. 같은 프로젝트에서 여러 채팅이 시작되면 최초 분석을 공유합니다. 설치·추출이 실패하거나 취소되면 분석을 건너뛰고 코드 변경을 진행하지 않습니다. 일반 대화는 `codeWork=false`로 이 절차를 생략합니다.

최초 추출에서 코드 노드가 없으면 빈 프로젝트·제외 규칙·미지원 언어 가능성을 보고서에 명시합니다. 마스터가 실제 파일을 확인하고 초기 구조를 분석해야 진행할 수 있습니다. 기존 그래프가 있는 상태에서 빈 결과로 갱신을 시도하면 이전 그래프를 보존합니다.

Graphify는 코드 파서로 구조를 추출하며 **로컬 AI 모델은 사용하지 않습니다**. 현재 선택된 마스터가 추출 보고서와 관련 소스를 읽고 구조·변경 영향·검증 계획을 직접 분석합니다. `project_graph(record_analysis, summary)`로 기록하면 채팅에 표시되고 작업자에게 전달됩니다. 코드 작업은 이 기록이 있어야 배정·변경할 수 있습니다. 작업자는 마스터 대신 이 기록을 제출할 수 없습니다. 구조 지도는 프로젝트별로 재사용하며, 마스터의 해석은 새 코드 작업마다 수행하므로 선택한 모델의 대화 사용량에 포함됩니다.

## 화면과 에이전트

- 노드를 선택하면 파일·라인·연결 정보를 표시합니다. **파일 위치**는 탐색기에서 해당 파일을 선택합니다. 소스 파일을 프로그램으로 실행하지 않습니다.
- 그래프를 드래그하거나 확대/축소할 수 있습니다. 커뮤니티 필터와 함수·파일·개념 검색으로 범위를 좁힙니다.
- 연결 수가 많을수록 노드 원 자체가 커집니다. 핵심 노드는 은은한 테두리를 두르고, 선택한 노드는 링과 관련 연결선으로 강조합니다. 원본 영상의 색조와 강조 연출을 참고했으며 임의로 노드나 연결을 추가하지 않습니다.
- **설명**은 선택한 노드의 연결과 근거를 출력합니다. 도착 노드를 검색하여 두 노드의 최단 연결 경로를 조회할 수 있습니다. 경로 탐색은 양방향 연결을 사용하며 실행 순서를 의미하지 않습니다.
- **그래프 검색**은 Graphify의 로컬 탐색 결과를 보여줍니다. 자연어 답변이 필요하면 채팅에서 마스터에게 그래프를 참조하도록 요청하세요.
- **분석 보고서 보기**에서 Graphify가 생성한 구조 보고서를 읽습니다. EXTRACTED, INFERRED, AMBIGUOUS, UNKNOWN 표시를 구분하고 실제 수정 전 소스를 확인해야 합니다.
- 마스터와 작업자의 `project_graph` 도구는 `status`, `build`, `query`, `explain`, `path`를 제공합니다. `record_analysis`는 마스터 전용입니다. `build`는 백그라운드로 실행하며 코드 작업 중 갱신했다면 마스터가 다시 `route_request(codeWork=true)`로 지도를 받고 분석을 기록합니다. 도구의 프로젝트는 현재 채팅에서 결정됩니다. 다른 프로젝트 경로나 실행 파일을 인수로 지정할 수 없습니다.

## 저장과 분석 범위

캐시는 `%APPDATA%\AI_ChatterBox\graphify` 아래에 프로젝트 ID와 실제 폴더 경로별로 분리됩니다. 원본 작업 폴더에 Graphify 출력이나 전역 스킬·훅을 설치하지 않습니다. 분석에 실패하거나 중지하면 이전에 완성한 그래프를 유지합니다. 동시에 조회 중이지 않다면 최근 두 세대만 남깁니다.

코드만 추출하며 `.gitignore`와 `.graphifyignore`를 따릅니다. Graphify 자체의 PDF·문서·영상·이미지 의미 추출과 별도 모델 호출은 사용하지 않습니다. `GRAPHIFY_BACKEND=none`과 `--code-only`를 적용하며 영상 생성은 수행하지 않습니다. 코드 지도와 보고서는 현재 마스터에게 전달되므로 선택한 모델 제공자가 해당 내용을 처리합니다. 생성된 외부 HTML을 Electron에서 실행하지 않고 앱의 로컬 SVG 화면으로 표시합니다.

그래프는 생성 당시 스냅샷입니다. 자동 파일 감시는 없으며 생성 후 5분이 지나면 갱신 안내를 표시합니다. 이는 파일 변경을 감지했다는 뜻이 아닙니다. 코드를 수정한 뒤 **그래프 업데이트**를 실행하세요. 화면은 선택한 노드와 조회 결과·이웃을 우선하여 최대 72개 노드·180개 연결을 그립니다. 기본 보기에서는 연결 수가 큰 노드와 각 커뮤니티의 대표 노드를 골라 표시합니다. 검색과 경로 조회는 전체 그래프를 사용합니다. JSON이 32MB를 넘으면 `.graphifyignore`로 범위를 줄여야 합니다.
