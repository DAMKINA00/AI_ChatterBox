## 재실행

```powershell
npm run typecheck
npm test
npm run build
node scripts/e2e-core-lifecycle.mjs
node scripts/e2e-chat-search-drop.mjs
npm run build:usage
node scripts/e2e-usage-companion.mjs
```

Usage 프로세스 검사는 기존 모니터를 정상 종료한 상태에서 실행합니다. 기존 계정 설정은 읽기 전후 해시만 비교하며 테스트 데이터는 `.scratch`에 분리합니다. 설치본으로 검사하려면 `E2E_EXE`와 `E2E_USAGE_EXE`에 해당 실행 파일을 지정합니다.
