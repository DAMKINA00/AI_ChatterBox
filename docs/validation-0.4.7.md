# 0.4.7 폴더·메뉴·한도·작업 목록·자동 승인 검증

검증일: 2026-10-15. 기준 커밋: 0.4.6 `5f09fb2`.

## 변경

- 프로젝트 폴더의 단일 클릭은 열림 상태를 유지하고 더블클릭으로 접거나 펼칩니다. 키보드 Enter/Space로도 전환할 수 있습니다. 채팅 선택과 개별 기록의 기존 조작은 유지합니다.
- 채팅 `…` 버튼을 마우스가 벗어나면 사라지는 레이아웃에서 고정된 자리로 옮겼습니다. 메뉴를 연 뒤에도 기준 버튼의 좌표가 유지됩니다. 프로젝트 메뉴도 버튼 근처에 표시되는지 확인했습니다.
- 새 프로젝트의 지시당 배정 한도는 100회, 그중 리뷰 한도는 20회입니다. 설정 범위는 배정 1–999회, 리뷰 0–99회입니다. 이전의 숨은 24회 제한과 작업자 수에 따른 가산을 제거해 설정값을 그대로 적용합니다. 시간 제한은 추가하지 않았습니다.
- 기존 프로젝트의 저장값이 8/3 조합이면 최초 실행 시 한 번 100/20으로 올립니다. 다른 사용자 설정은 유지하고, 이후 직접 8/3으로 저장하면 그 값도 유지합니다. 누락·비정상 숫자는 기본값, 범위 밖 숫자는 경계값으로 정규화합니다.
- 같은 담당자의 연속된 도구 실행이 2개 이상이면 `작업 목록`으로 묶어 기본적으로 접습니다. 메시지·담당자 경계를 넘지 않고, 단일 도구와 승인·파일 변경·이미지·결과물은 기존 형태를 유지합니다. 목록을 펼친 뒤 기존 도구 상세를 열 수 있고 진행·오류 수는 접힌 상태에서도 표시합니다.
- 마스터 자동 판단과 고위험 위임을 모두 켜면 `ask_user`·판단 실패·미응답도 사용자에게 넘기지 않고 자동 허용하며 이유를 기록합니다. 명시적 거부와 실행·작업 범위 제한, 계획·리뷰 중 수정 금지는 먼저 적용합니다. 설정이 꺼져 있거나 직접 승인 모드이면 기존 사용자 승인 경로를 유지합니다. 설정 설명에 이 동작을 명시했습니다.

## 범위와 적용

화면 검증은 격리 데이터와 합성 이벤트, 정책 검증은 가짜 판단 결과를 사용했습니다. 실제 사용자 작업의 고위험 명령을 실행하거나 승인하지 않았으며 실제 CLI 판단·OS UAC·Google 계정 호출은 이번 변경에서 재수행하지 않았습니다. 프로덕션 앱을 종료하거나 다시 실행하지 않았습니다. 작업이 끝난 뒤 기존 앱을 완전히 종료하고 새 포터블을 실행해야 설정 변경과 UI가 적용됩니다.
