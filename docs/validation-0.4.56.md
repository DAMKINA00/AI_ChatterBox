# 0.4.56 — 백그라운드 CLI 조회 안정화

## 반영 내용

- GitHub의 v0.4.55와 승인 처리 병합(`1720001`)을 반영했습니다. 조회 파이프라인 판별과 같은 Codex 실행 턴에 승인 거절 사유를 전달하는 동작을 포함합니다.
- Antigravity 사용량 조회 자식 프로세스에만 `AGY_CLI_DISABLE_AUTO_UPDATE=true`를 지정합니다. 조회가 CLI 자동 업데이트를 시작하지 않도록 하며, 전달받은 계정 환경과 부모 프로세스 환경은 수정하지 않습니다.
- Windows 프로세스 트리 종료의 `taskkill` 호출에 `windowsHide=true`를 적용했습니다. 기존 종료 대상과 종료 방식은 유지합니다.
- 버전은 `package.json`과 `package-lock.json` 모두 0.4.56으로 올렸습니다.

## 확인 범위와 검증

- 사용량 조회 호출 경로와 공통 프로세스 종료 헬퍼의 호출부를 검토했습니다.
- 사용량 회귀 검사에서 자식 프로세스의 자동 업데이트 차단, 숨김 실행, 계정 환경 전달, 부모·호출자 환경 보존을 확인합니다.
- Node와 renderer TypeScript 검사 통과.
- Electron Vite 빌드 통과.
- 전체 단위 테스트 재검사 724/724 통과. 최초 실행의 기존 원격 숫자 설정 검사 1건에서 HTTP 400이 관측됐으나 단독 실행과 전체 재실행에서는 통과했습니다. 이 일회성 실패의 원인은 확정하지 않았습니다.

실제 모델 요청, Windows 설치파일 패키징과 설치는 이번 버전업 작업에 포함하지 않았습니다. 계정 자격 증명과 기존 앱 데이터는 변경하지 않았습니다.
