# 0.4.6 승인 대기 요청의 하단 표시 검증

검증일: 2026-10-15. 기준 커밋: 0.4.5 `aa0b19f`.

## 문제와 수정

승인 요청 뒤로 마스터·작업자의 대화와 도구 출력이 쌓이면 요청을 다시 찾기 어려웠습니다. 전체 대화와 마스터 대화에서 미처리 승인 요청을 시간순 기록과 분리해 대화 맨 아래에 표시합니다. 이후의 메시지, 협의와 작업 진행 표시는 그 위에 쌓입니다. 여러 미처리 요청은 접수 순서를 유지합니다.

- 승인·거부되면 해당 요청만 하단에서 빠지고 원래 대화 시점에 처리 기록이 남습니다. 중지·완료로 만료된 요청도 기존 기록 위치에 남습니다.
- 작업자·개별 협의 화면은 기존 시간순 기록과 ‘마스터 대화에서 확인’ 연결을 유지합니다.
- 저장 이벤트, 원본 승인 ID, 승인 정책, 위험도·버튼 제한, 알림과 실제 승인 처리 경로는 변경하지 않았습니다.
- 하단 고정 오버레이가 아니라 대화의 마지막 항목입니다. 과거 기록을 읽으려고 위로 스크롤하면 기존 ‘맨 아래로’ 버튼으로 돌아갈 수 있습니다.

## 검증 범위

승인 버튼의 원본 ID 전달과 화면 갱신은 격리된 앱에서 가짜 이벤트·승인 응답으로 확인합니다. 실제 사용자 작업을 허용하거나 거부하지 않으며, 실환경의 고위험 명령·UAC·Google 계정 호출은 이번 변경의 검증 대상이 아닙니다. 진행 중인 프로덕션 앱을 중단하거나 재시작하지 않습니다. 기존 작업이 끝난 뒤 앱을 완전히 종료하고 새 포터블을 실행해야 적용됩니다.
