# 0.4.25 계정 관리·추론·승인 설정 검증

2026-10-20 검증 결과입니다.

## 변경 내용

- 제미나이 웹 계정 관리에 로그아웃과 슬롯 삭제를 추가했습니다. 로그아웃은 슬롯 이름·배정 설정을 유지하며 Google 로그인 정보와 연결된 AI Studio 계정 등록을 정리합니다. 슬롯 삭제는 같은 정리 후 등록 슬롯을 제거합니다. AI Studio 정리에 실패하면 슬롯을 삭제하지 않습니다.
- 실행 중인 Web 작업자나 AI Studio 계정은 정리할 수 없습니다. 처리 도중 새로 생긴 브라우저 초안·생성도 창을 닫기 전에 확인합니다. 이전 상태 조회가 늦게 끝나도 로그아웃 상태를 덮어쓰지 않습니다.
- 계정의 대화 연결 ID와 작업자 배정 정보는 해제하고 앱의 대화·협의·로컬 맥락 기록은 유지합니다. 다른 계정의 로그인은 건드리지 않습니다.
- 마스터 추론 선택은 채팅 상단과 프로젝트 설정에 유지합니다. 작업자 추론은 프로젝트 설정에서만 변경하며, 기본값은 자동 배정입니다. 과거 채팅의 작업자 추론 override는 실행에 적용하지 않습니다.
- 승인 방식은 전체 위험 승인, 마스터 자동 승인, 관리자 직접 승인입니다. 전체 위험 승인은 고위험도 마스터에게 위임하며 기존 고위험 위임의 자동 허용 동작을 유지합니다. 명시적 거부·작업 범위·계획 모드 제한은 계속 적용됩니다. 이전 고위험 위임 프로젝트는 새 모드로 읽습니다.
- 계획 제목 시작의 기존 기본 이름 `[Antigravity N호]`, `[Gemini N호]`는 `[제미나이 N호]`로 표시합니다. 저장된 이벤트·사용자 지정 이름·본문의 실제 CLI 명칭은 유지합니다.

## 검증 범위와 적용

실제 Google 계정 로그아웃이나 AI Studio 계정 삭제는 수행하지 않았습니다. 모델 대화·코딩·영상 생성도 추가 실행하지 않았습니다. `smoke-effort.mjs`는 기존 명시적 xhigh 검증 의도를 유지하도록 테스트 설정을 조정했으며 이번에는 실행하지 않았습니다.

사용자가 작업 중인 기존 0.4.24 앱과 시작 메뉴 바로가기는 유지했습니다. 기존 실행기·앱의 PID와 시작 시각이 그대로이며 이전 포터블의 SHA-256도 변경되지 않았습니다. 0.4.25 포터블은 별도 파일로 준비했습니다. 작업을 마친 뒤 새 포터블을 실행해야 이번 변경이 적용됩니다.
