# AI_ChatterBox

채팅 하나에 지시하면 **마스터**가 계획을 세우고, 일의 양에 맞춰 **클로드 N호**(Claude Code), **지피티 N호**(Codex), **제미나이 N호**(Antigravity) 작업자를 꾸려 구현과 리뷰를 나눠 맡기는 Windows 데스크톱 앱입니다 (Electron + React + TypeScript).

![GPT 오케스트레이터가 GPT에 구현, Claude에 리뷰를 맡긴 화면](docs/screenshots/v2-fix-gpt.png)

- **프로젝트 = 작업 폴더.** 프로젝트 아래에 채팅이 있고, 각 채팅을 펼치면 `마스터 대화 · 클로드 1호 · 클로드 2호 · 지피티 1호 … · 협의 N (보낸 쪽 → 받는 쪽)`이 트리로 보입니다.
- **작업자 팀 (0.3):** 마스터가 필요한 만큼 작업자를 만들고(`spawn`) 닉네임으로 일을 맡깁니다(`ask`). 고칠 범위(scope)가 겹치지 않는 구현과 리뷰는 동시에 진행되고, 작업자끼리도 닉네임으로 서로 묻습니다. 범위 밖 쓰기는 자동 거부, 서로 기다리는 순환 호출은 거절됩니다. 기본 동시 한도는 클로드 3명 + 지피티 3명 + 제미나이 1명이며 프로젝트 설정에서 조절합니다.
- **슬래시 명령 (0.3):** `/plan`(계획 → 실행/수정/취소), `/goal`(목표를 끝날 때까지 진행), `/review`, `/status`, `/model`, `/new`, `/stop`, `/compact`.
- **마스터와 세 계열 작업자.**
  - **마스터:** 요청 이해·작업 배정·결과 검토·최종 취합을 담당합니다. 간단한 답변과 사전 확인은 직접 하고 본격적인 분석·구현·이미지·문서 제작은 작업자에게 맡깁니다. Claude 모델을 고르면 Claude Code로, GPT 모델을 고르면 Codex로 실행됩니다.
  - **클로드 N호 / 지피티 N호 / 제미나이 N호:** 클로드·지피티는 자기 세션에서 맡은 범위의 파일을 고칩니다. 제미나이는 웹·CLI 모두 문장 다듬기·캐릭터 대사·문서 본문 등 글쓰기 전용입니다.
  - **모델 설정:** 마스터·클로드·지피티·제미나이 모델을 프로젝트마다 정하고, 채팅 상단에서 채팅별로 바꿀 수 있습니다. Gemini는 로그인한 Pro 계정에서 제공하는 모델만 표시합니다.
- **협업 흐름:** 계획 → 작업자 구성 → 범위를 나눠 구현 → 다른 작업자가 리뷰 → 수정 → 최종 보고. 협의는 채팅 안에 카드로 실시간 표시됩니다 (예: "마스터 → 클로드 2호 · 구현 · src/ui/**").
- **승인:**
  - **적용 대상:** 마스터와 작업자의 파일 수정·명령 실행에 같은 프로젝트 승인 설정을 적용합니다. 자동 승인은 별도의 판단 세션이 맡고, 실패·시간 초과·추가 결정이 필요하면 사용자 카드로 돌아옵니다.
  - **카드 버튼:** 직접 승인에서는 **이번만 허용 / 이 채팅 동안 허용 / 거부** 중에서 고릅니다. 고위험 요청은 채팅 전체 허용을 기억하지 않습니다.
  - **고위험 위임:** 설정을 켜면 판단 세션이 사용자 지시 범위 안의 고위험 요청도 허용·거부할 수 있습니다. 설정 변경은 이전 승인 기억을 초기화합니다. `/plan`과 리뷰·의견의 수정 금지는 계속 적용됩니다.
  - **위험 우회 플래그 안 씀:** `--dangerously-skip-permissions`나 Codex yolo 모드는 쓰지 않습니다.
- **첨부:** 📎 버튼, **Ctrl+V** 이미지 붙여넣기, 끌어다 놓기를 지원합니다. 이미지는 Claude와 Codex 모두 직접 봅니다.
- **진행 중 조작:** 기본 보내기와 `Enter`는 마스터에게 즉시 전달합니다. `Alt+Enter`는 다음 단계 전달, `Shift+Enter`는 줄바꿈입니다. **중지**를 누르면 마스터와 작업자가 모두 멈춥니다.
- **그 밖의 기능:** 마크다운과 코드 하이라이트, 도구 호출 카드, diff 보기, 다크/라이트 테마, 사용량 표시(Claude·GPT·Gemini 5시간·주간), 채팅과 메시지 검색, 창 크기 기억.
- **작업자 가로줄 (0.3.1):** 상단 메뉴 아래에 생성된 작업자를 표시합니다. 활성 작업자가 앞에, 회색으로 표시한 해제 작업자는 뒤쪽 별도 구역에 있으며 모두 기록을 열 수 있습니다.
- **캐릭터 (0.3.1):** 무광 눈동자와 같은 치비 화풍으로 맞춘 마스터·클쨩·짚쨩의 12종 표정을 표시합니다. `set_expression(expression)`은 호출한 역할의 다음 대사에 연결되고 과거 대사의 표정은 보존합니다. 실제 작업·승인·오류 상태는 별도 배지로 표시합니다. [표정 갤러리](docs/character-gallery.html)와 [제작 기준](docs/character-art.md)을 보관합니다.

## 0.4.2 변경

- **이전 웹 계정 우선:** 기존 작업자의 웹 계정을 먼저 확인하고, 잔여량이 10%를 넘으며 쉬고 있으면 같은 웹 대화로 이어서 작업합니다. 사용할 수 없으면 쉬고 있는 계정 중 잔여량이 가장 많은 계정에 배정합니다.
- **배정 대기와 재개:** 모두 작업 중이거나 한도가 부족하면 요청과 초안을 보존하고 기다립니다. 작업 상태는 10초마다, 실제 한도는 계정별 최소 60초 간격으로 다시 확인합니다. 이미 사용한 계정도 초기화 후 다시 배정할 수 있으며 중지 버튼으로 대기를 취소합니다.

## 0.4.1 변경

- **웹 계정 관리:** 왼쪽 아래 또는 제미나이 모델 메뉴의 `Gemini 웹 계정 관리`에서 최대 10개 계정을 추가하고 각각 로그인합니다. 계정 이름·자동 배정 여부·현재/주간 잔여량·초기화 시각을 관리하며, 기존 계정 1의 로그인과 대화는 유지합니다. 메인 화면에는 웹 사용량을 별도로 표시하지 않습니다.
- **잔여량 우선 배정:** 현재·주간 한도 중 더 적게 남은 비율을 비교해 가장 여유 있는 계정을 배정합니다. 작업 중인 계정과 배정에서 제외한 계정은 선택하지 않으며, 확인되지 않은 수치를 100%로 간주하지 않습니다.
- **자동 인계:** 잔여량이 10% 이하가 되고 더 여유 있는 계정이 있거나 한도에 도달하면 현재 요청·이전 완료 응답·미완성 초안을 넘겨 이어서 작성합니다. 인계 중에도 한 협의를 유지합니다. 다른 계정도 사용할 수 없으면 초안을 보존하고 미완료로 보고하며, 사용자 중지 후에는 재배정하지 않습니다.

## 0.4.0 변경

- **Gemini 웹 Argon:** 제미나이 모델 메뉴 → `웹 계정 1 연결…`에서 전용 브라우저에 로그인하고 `Argon 모델 사용`을 누릅니다. 계정 1개와 웹 작업자 1명을 연결하며 로그인과 작업자별 웹 대화를 재사용합니다.
- **마스터 연동:** 마스터가 앱의 `spawn/ask`로 `writing`(글쓰기)을 맡기고 응답을 협의 카드에 표시한 뒤 취합합니다. 본문과 UTF-8 텍스트 첨부를 지원합니다. 웹·CLI 제미나이에 코드 분석·구현·테스트·기술 리뷰는 배정할 수 없습니다. 기술적 사실 확인과 결과물의 파일 반영은 클로드·지피티가 맡습니다. 수정하지 않은 예전 선호 기본값도 새 역할에 맞춰 갱신합니다.
- **웹 사용량:** Gemini의 사용량 한도 화면에 표시된 현재·주간 사용률과 초기화 시각을 동기화합니다. CLI 사용량과 구분하며 실패·보안 확인 시 이전 수치를 새 수치처럼 표시하지 않습니다.
- **중지와 로그인 복구:** 중복 작업을 거절하고 수동 초안을 보존합니다. 중지는 웹 응답 생성을 중단합니다. Google 보안 확인이 뜨면 자동 재시도를 멈추며 전용 브라우저에서 직접 확인합니다.

## 0.3.5 변경

- **추론 설정:** 프로젝트 설정·채팅 상단·상태 창에서 역할별로 설정합니다. 마스터 기본값은 `xhigh`, 작업자는 `자동 배정`이며 마스터가 각 요청의 난이도에 따라 `medium`·`high`·`xhigh` 중에서 선택합니다. 사용자가 직접 고른 작업자 값이 있으면 우선 적용합니다. 선택 메뉴는 해당 CLI가 알려준 지원 수준만 표시합니다.
- **적용 기록:** 협의 카드에 적용한 추론 수준을 표시하고 배정 이유와 함께 저장합니다. 선택한 수준을 모델이 지원하지 않으면 지원 범위 내에서 낮춰 적용하고 요청값도 보존합니다. Gemini Pro의 현재 모델에서는 `medium`·`high`를 사용합니다. 추론값은 CLI에 전달하는 설정이며 Claude 조직 정책 등 실제 서비스가 조정할 수 있으므로 내부 추론량의 실제 측정값으로 해석하지 않습니다.
- **추가 지시:** 작업 중인 채팅은 **즉시 전달**과 기존 **다음 단계 전달**을 별도 버튼으로 제공합니다.
- **대화 표시:** Discord형 대화처럼 왼쪽에 36px 캐릭터, 이름, 본문을 놓고 오른쪽에 저장 시각을 표시합니다. 역할 앞 장식 점은 제거했습니다.
- **파일·이미지 표시:** 파일별 링크에서 열기·탐색기에서 보기·다운로드를 선택하고, 로컬 이미지 링크는 대화 안에서 미리 봅니다. Codex raw citation(`:codex-file-citation{...}`)도 같은 파일 링크로 변환합니다.
- **Gemini 캐릭터:** Gemini도 같은 치비 화풍의 12종 표정 아이콘(중립 포함)을 사용합니다. [표정 갤러리](docs/character-gallery.html)와 [제작 기준](docs/gemini-character-art.md)에 기록했습니다.
- **시간 제한 제거:** 지시 전체와 작업자 협의에 앱의 자동 종료 시간을 적용하지 않습니다. 기존 프로젝트의 시간 제한도 무시하고 필요할 때 **중지** 버튼으로 마스터와 작업자를 멈춥니다. 배정·리뷰 횟수 제한과 CLI 서비스의 네트워크·도구 제한은 별개입니다.
- **기본 인원:** 새 프로젝트는 클로드 3명·지피티 3명·제미나이 1명입니다. 기존 프로젝트에서 저장한 인원은 유지합니다.
- **Gemini 원본 보관:** 현재 Antigravity CLI에서 안전한 보관·복원 기능을 확인하지 못해 자동 보관은 추가하지 않았습니다. ChatterBox 기록·해제·재호출은 계속 지원합니다.
- **검증 기록 초안:** [0.3.5 검증 기록](docs/validation-0.3.5.md)에 확인된 범위와 남은 검증 항목을 적었습니다.

## 0.3.4 변경

- **Google AI Pro 작업자:** Antigravity CLI에 로그인한 계정의 Gemini 모델을 사용합니다. 프로젝트·채팅별 모델, 선호 작업·주의점, 동시 작업자 수를 설정합니다. Pro 자동 선택은 계정이 제공하는 최신 Flash Medium을 우선하며, Ultra 전용 Argon이나 별도 API 키로 전환하지 않습니다.
- **기존 협업 연결:** 마스터가 `spawn(kind=gemini)`로 만들고 요청·진행·응답을 같은 협의 카드에서 취합합니다. 승인·구현 범위·리뷰 수정 제한과 해제 작업자 재사용을 적용합니다. 기본 업무는 계속 클로드 우선이며 중요한 오류의 클로드·지피티 독립 조사도 유지합니다.
- **표시:** 제미나이는 별 모양 아이콘으로 구분합니다. CLI가 보고한 입력·출력·생각·캐시 토큰과 턴 시간 기준 평균 속도를 표시합니다. 계정 잔여 한도는 임의 계산하지 않습니다.
- **프로젝트 설정창:** 너비를 최대 1000px로 넓히고 화면 크기에 따라 작업자 설정을 1~3열로 배치합니다. 선호 작업·주의점 입력칸을 키우고 오른쪽 아래 크기 조절 표시를 없앴습니다.
- **설정:** [Antigravity 설치·로그인과 제한](docs/gemini-pro.md)을 참고하세요. 마스터로 Gemini를 선택하는 기능과 Gemini 이미지 생성은 이번 버전에 포함하지 않습니다.

## 0.3.3 변경

- **Claude 우선 배정:** 일반 분석·구현·테스트·문서는 클로드를 우선합니다. 지피티는 이미지, 중요한 교차검증, 사용자 지정, 클로드의 한도·과부하에 따른 재배정에 사용합니다. 간단한 질문은 작업자 없이 마스터가 직접 답합니다. 기존 프로젝트의 수정하지 않은 기본 선호는 새 기준으로 바뀌며, 직접 작성한 선호는 유지합니다.
- **중요 오류 양쪽 조사:** 마스터가 중요하다고 판단한 버그·오류는 클로드와 지피티에게 같은 자료로 독립 조사를 맡깁니다. 두 계열의 실제 조사 결과가 돌아와야 수정·완료 단계로 넘어갑니다. 마스터는 공통점·차이·근거를 비교해 취합하며, 한쪽이 실행 불가하면 미완료 사유를 표시합니다.
- **접힌 요청:** 협의 카드의 내부 요청과 첨부는 기본으로 접고, `요청` 행을 눌러 펼칩니다. 작업자의 진행 대사와 결과는 계속 표시합니다.
- **간결한 사이드바:** 진행 중인 협의는 모두 표시하고, 모두 종료되면 마지막 한 건만 남깁니다. 이전 협의는 전체 대화 기록에서 확인합니다. 해제 작업자는 회색으로 표시하고 이름 뒤의 `(해제)`는 제거했습니다.
- **진행 채팅 바로 열기:** 아래쪽의 작업 중·승인 대기 항목을 누르면 해당 채팅의 전체 대화가 열립니다.
- **마스터를 통한 승인:** 작업자의 사용자 승인 요청도 마스터 대화에 모읍니다. 요청한 작업자와 판단 이유를 표시하고, 작업자 기록에서는 마스터 대화로 이동합니다. 결정은 원래 작업자의 요청에 전달됩니다.
- **알림:** 승인·질문 대기 시 한 번, 1분 동안 해결되지 않으면 한 번 더 알립니다. 마스터의 전체 작업 완료는 한 번 알리고, 개별 작업자 완료와 목표 진행 중간에는 완료 알림을 보내지 않습니다. 알림을 누르면 해당 채팅을 엽니다.
- **작업자 재사용:** 해제된 같은 계열 작업자를 낮은 번호부터 다시 활성화합니다. 기존 번호·기록·CLI 대화 ID를 유지하며 동시에 필요한 수만 추가합니다.
- **모션그래픽:** 애니메이션 코드·타임라인·연출 제작은 클로드 우선, 생성 이미지 소재가 필요한 부분만 지피티에 맡깁니다.
- **원본 CLI 대화 정리:** 작업자 협의가 끝나면 원본 대화를 보관하고 재호출 시 복원합니다. Codex는 App Server의 `AI AGENT` 프로젝트와 보관 API를 사용합니다. Claude CLI는 이름에 `[AI AGENT]`를 붙이고, 종료한 세션의 원본 파일을 별도 폴더에 보관했다가 `--resume` 전에 복원합니다. ChatterBox 기록은 항상 남깁니다. Claude Desktop의 별도 프로젝트에 CLI 대화를 넣는 기능은 지원되지 않습니다. Codex 데스크톱의 프로젝트 표시에는 앱 버전·프로젝트 API 지원 여부에 따른 제한이 있습니다.
  - 실행 중인 Codex 데스크톱은 외부에서 만든 프로젝트 목록을 캐시할 수 있습니다. 작업 종료 후 Codex를 다시 열어 목록을 갱신합니다. 이 릴리스에서는 원본 프로젝트 등록·보관·복원 API를 실제 확인했으며, 실행 중인 사용자 앱을 재시작하지는 않았습니다.

## 0.3.2 변경

- **배정 기준:** 프로젝트 설정의 클로드·지피티 선호 작업과 주의점을 참고합니다. 기본은 소스 분석에 클로드, 이미지 생성에 도구 사용이 확인된 지피티이며, 사용자 지정·작업량·현재 사용량을 함께 고려합니다. 작업자 모델은 상단 선택을 따릅니다.
- **보이는 협업:** CLI 내부 작업자 생성은 끄고 앱의 `spawn`/`ask`/`ask_parallel`로 위임합니다. 배정 이유·요청·실시간 응답·완료 요약을 대화에서 확인합니다. 지시별 실제 결과가 누락되면 한 번 보완하고 계속 실패하면 미완료로 표시합니다. 이전 버전에서 앱에 저장하지 않은 내부 작업자의 전체 대화는 복원되지 않습니다.
- **이미지:** 지피티의 생성 진행·결과 미리보기·보관 파일을 표시하고 마스터에게 산출물 경로를 전달합니다. 로그인·모델·이미지 도구 사용 가능 여부에 따라 실행 가능 여부가 달라집니다.
- **파일 링크:** Windows 경로·상대 경로·file URL을 클릭하면 파일 열기, 탐색기에서 보기, 다른 이름으로 저장(다운로드)을 선택합니다. 웹 링크는 브라우저에서 열고, 파일이 없거나 열기에 실패하면 오류를 표시합니다.
- **작업자 사용량:** 마스터와 작업자별 입력·출력·캐시 토큰, 턴 경과 시간, 마지막 턴 평균 출력 tok/s를 표시합니다. 속도는 도구·승인·위임 대기까지 포함한 턴 시간 기준이며 순수 서버 생성 속도가 아닙니다. Codex는 사용량 이벤트 시 갱신하고 Claude는 턴 종료 시 제공된 수치로 갱신합니다. 이전 기록에 수치가 없으면 사용량 대기로 표시합니다. 계정 전체의 남은 한도와 구분합니다.

## 실행 파일

`dist\AI_ChatterBox-0.4.2-portable.exe`를 더블클릭하면 됩니다. 설치는 필요 없습니다. 기존 작업이 끝난 뒤 앱을 종료하고 새 파일로 실행하세요.

- 실행할 때마다 임시 폴더에 압축을 풀기 때문에 처음 창이 뜰 때까지 10초쯤 걸립니다.
- 실행기와 내부 앱 모두 Windows 관리자 권한을 요청합니다. UAC를 취소하면 실행되지 않습니다. CLI의 쓰기·명령 승인은 Windows 권한과 별도로 적용됩니다.
- 서명하지 않은 exe라서 처음 실행할 때 SmartScreen이 막으면 **추가 정보 → 실행**을 누르세요.
- 데이터는 `%APPDATA%\AI_ChatterBox`에 저장됩니다.
  - `chatterbox.db`: 프로젝트, 채팅, 협의, 이벤트
  - `attachments\`: 첨부 파일
  - Codex 원본은 CLI의 활성/보관 기록에 유지합니다. Claude 작업자 원본은 활성 상태에서 `~\.claude\projects`, 완료 후 `~\.claude\chatterbox-archived-sessions`에 보관합니다 (`CLAUDE_CONFIG_DIR` 지정 시 해당 경로 사용). 마스터 기록은 자동 보관하지 않습니다. 보관 실패·지원되지 않는 색인 형식은 기록을 삭제하지 않고 안내합니다.
- v0.1 데이터가 있으면 처음 실행할 때 "가져온 세션" 프로젝트로 옮겨집니다.

| 실제 CLI 수정 제한·판단 분기 | 10개 검사 통과. `/plan`·리뷰는 수정하지 않았고, 고위험 위임 끄기는 사용자 카드로 복귀, 켜기는 명시된 테스트 대상 허용. 폴더 밖 쓰기는 판단만 검사하고 실제 실행하지 않음 |
| 관리자 실행 | 내부 앱·포터블 실행기의 requireAdministrator 매니페스트 확인. UAC 승인 후 포터블 후보에서 Claude·Codex 마스터 자식 프로세스 각각 관리자 토큰=true, 관리자 조회 fltmc 종료 코드=0 확인. UAC 취소 동작은 실측하지 않음 |

실제 CLI 검사는 기존 로그인으로 격리 작업 폴더에서 실행했습니다. 기존 앱 데이터는 수정하지 않았습니다. 관리자 검사는 시스템을 변경하지 않는 조회 명령만 실행했습니다. 그림을 포함해 재패키징한 최종 파일은 매니페스트를 다시 검사합니다. UAC 취소 동작과 모든 종류의 관리자 작업까지 검증한 것은 아닙니다.

권한 설정 참고: [Codex App Server](https://learn.chatgpt.com/docs/app-server), [Claude Code permissions](https://code.claude.com/docs/en/permissions), [Electron Windows 설정](https://www.electron.build/docs/api/app-builder-lib.interface.windowsconfiguration/), [Portable 설정](https://www.electron.build/docs/api/app-builder-lib.interface.portableoptions/).
